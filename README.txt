RIO HMK Jobs — starter prototype

WHAT THIS IS
- A responsive, single-file website prototype.
- Includes sample vacancies, keyword search, location/category filters, job detail popups, and a demo employer-interest form.
- Works locally in a modern browser without installing anything.

IMPORTANT
- All listed jobs are fictional sample listings.
- The employer form does not send or save information.
- There is no database, login, real CV upload, payment integration, or live application submission yet.
- Do not publish this as a live job board until the backend, security, privacy notice, employer verification, and real listings are ready.

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. On a phone, transfer the file to the device and open it in a browser, or preview it on a computer first.

NEXT BUILD MILESTONE
Connect a hosted database and authentication, then add secure employer accounts, admin approval, real job records, and a payment workflow.
